# Koamishin Auth documentation

Koamishin Auth is a self-hosted authentication and user-management platform. It includes a Filament administration panel, tenant organization and application records, independent application identities scoped per environment, and queued user webhooks. This documentation describes the behavior in this repository and helps you set up and operate your own instance.

## Start with Koamishin Auth

1. [Install Koamishin Auth](getting-started/installation.mdx) and create the first administrator.
2. [Configure the environment](getting-started/configuration.mdx), including the [REDACTED], URL, mail, and queue.
3. [Run the development services](getting-started/local-development.mdx); the installation guide also shows how to create an organization and application.

## Understand the current boundaries

OAuth userinfo, the management API, and user webhooks enforce the application-environment checks described in this guide. User identities are scoped per application environment (`identity_namespace`), preventing cross-application collisions while allowing the same email, username, or phone number across applications. Super administrators have access to the Filament management panel, while application users are strictly isolated from administrative panel access. Although the server publishes discovery metadata, it does not currently issue OpenID Connect ID tokens or handle OIDC nonces. Read [tenancy and OAuth](guides/core-concepts.mdx) and [security](guides/security.mdx) before connecting applications or handling sensitive data.
